#   pip install -r requirements.txt        # ou: pip install -r requirements.lock.txt

# macOS: o lightgbm carrega a OpenMP (libomp.dylib) em tempo de execução, e a
# roda do pip não a traz. Sem ela, `import lightgbm` falha com
# "Library not loaded: @rpath/libomp.dylib". Instale com:  brew install libomp
#
# Duas versões importam de verdade para reproduzir os números: a do pandas,
# porque o comportamento de groupby com `observed` mudou entre versões e a
# absorção de efeitos fixos depende dele; e a do lightgbm, porque o remapeamento
# de categóricas por valor na previsão é coberto por um teste próprio.
